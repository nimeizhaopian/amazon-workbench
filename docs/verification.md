# 验证记录

本项目在 Windows、Node.js 24.16.0、DeepSeek Harness 0.2.2-rc.1 下验证。

已执行的检查包括：

- TypeScript 前端检查与 Vite 生产构建。
- 14 项 Node 自动化测试全部通过：演示与真实来源、任务持久化、跨店铺查询、草稿隔离、缺失销量、补货数量、CSV 转义、Amazon 分页与令牌、上游错误脱敏、进程中断恢复、重复启动不接触已有数据库、紫鸟默认禁用、API 来源与令牌校验、DSH 工具生命周期。
- Playwright + Microsoft Edge：运营概览、报告创建与 CSV 下载、草稿刷新持久化、切换店铺隔离、紫鸟配置与禁用状态、原生 DSH 界面、390px 窄屏无页面溢出、无未捕获浏览器异常。
- MCP stdio：发现 4 个工具，通过真实本地工作台读取演示库存。
- 原生 DSH 插件：注册 5 个业务工具，通过认证 API 读取演示库存。

未验证的外部路径：真实 DeepSeek 付费模型调用、真实 Amazon 账户授权及库存数据、真实紫鸟客户端与店铺操作。没有调用外部店铺写入。

截图和运行结果位于 codex-artifacts；演示任务与草稿保存在 .data，均不会加入 Git。
